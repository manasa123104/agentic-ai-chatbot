What is Tester?

The Tester checks that the Developer's code works. There are three kinds of test, and you can ask for any of them or all:

  • Unit tests – automated checks of small pieces of the code (one function or class at a time).
  • Automation (Selenium) – scripts that open a real browser and click through the app like a robot user.
  • Manual / Functional testing – step-by-step test cases (preconditions, steps, expected result) that a person runs by hand against the running app.

Pick the mode in the drop-down above the results. Everything it writes can be downloaded as files or a ZIP.
